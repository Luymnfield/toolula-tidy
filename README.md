# Toolula Tidy

A safe, fast cleaner for macOS (native SwiftUI app, macOS 14+).
It scans first and shows you everything; nothing is removed until you confirm. Items go to the Trash by default and every clean-up can be undone.

## Features

- **Clean**: app caches, logs and crash reports, developer junk (Xcode / Homebrew / npm / pip, etc.), browser caches, old files in Downloads, Trash, large files
- **Dev project junk**: `node_modules`, `.venv`, `target`, `build` and similar folders in old projects (only when the matching project file is next to them; projects changed in the last 30 days are unchecked by default)
- **Space map**: a treemap showing what takes up your disk; click into folders level by level
- **Duplicate files**: compares size first, then full content (SHA-256); at least one copy per group is always kept; files inside dev projects are unchecked by default
- **Startup items**: lists background programs that run at login / startup, with an on/off switch; items whose program no longer exists can be removed
- **Uninstall apps**: moves the app together with its settings, caches and data to the Trash; also finds leftovers of apps that were already deleted
- **Memory**: memory pressure, where memory goes, and the apps using the most (can be quit)
- **Undo**: every clean-up and uninstall can be put back; anything that couldn't be handled is listed with the reason
- **10 languages**: follows the system language or choose one in Settings; switches instantly
- **Fast**: parallel `getattrlistbulk` scanning; a full scan takes about 0.3 seconds

## Safety

- Only touches allowed locations in your home folder (caches, logs, etc.); never system files or protected apps (such as Safari)
- Every item's location is checked again right before it is removed
- Running apps and browsers are unchecked automatically; Downloads and large files are unchecked by default and are only ever moved to the Trash

## Build and install

```bash
./build_app.sh          # builds build/Toolula Tidy.app
./scripts/install.sh    # installs it into Applications
./scripts/make_dmg.sh   # packages build/ToolulaTidy-<version>.dmg
```

Builds a universal app (Apple silicon + Intel) by default; `FAST=1 ./build_app.sh` builds only for this Mac's chip, which is quicker. The version number lives in the `VERSION` file.

## Download

Download the DMG from [Releases](../../releases), open it and drag Toolula Tidy into Applications.
The app is not yet signed with an Apple Developer ID, so macOS blocks the first launch: go to System Settings › Privacy & Security and click "Open Anyway".

Installation guide: [docs/Toolula-Tidy-Install-Guide.pdf](docs/Toolula-Tidy-Install-Guide.pdf) (source: `docs/guide/install-guide.html`, printed to PDF with Chrome).

## Tests

```bash
./scripts/test.sh           # unit tests (run in a temporary fake home folder) + translation check
swift scripts/e2e.swift     # end-to-end test that opens the real app and clicks real buttons (needs Accessibility permission)
```

## Translations

UI text is written in the code as `L("<source text>")`. The source text (Simplified Chinese) is used as the key, and translations into the other languages live in `Localization/translations.json`.
`Localization/extract.py --check` reports missing translations, and the build warns about them automatically.

## Icon

The icon is generated by `scripts/make_icon.swift` (the chameleon shape comes from `Resources/icon_source.png`):

```bash
swift scripts/make_icon.swift Resources/icon_source.png Resources   # writes Resources/toolula_tidy_icon.png
```

Then resize it with `sips` and package it with `iconutil -c icns` into `Resources/AppIcon.icns`.
